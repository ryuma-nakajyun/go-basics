# Go Basics
Go言語の学習および検証を行うためのリポジトリです。

## 学習方針
単にプログラムを動作させることを目的とせず、
- なぜその設計を採用するのか
- エラーや異常系をどのように扱うのか
- 保守性・可読性をどのように確保するのか  
を考えながら学習・検証を行っています。

## 目的
- Go言語の基本文法の習得
- 関数設計の学習
- ログ出力の実装
- パッケージ管理の理解
- 保守しやすいコード構造の検証

## ディレクトリ構成
```text
ch01/
ch02/
ch03/
...
ch19/

orig01/
orig02/
orig03/
```
各ディレクトリは学習テーマごとに管理しています。

## 学習内容
- 基本文法
- 変数・定数
- 関数
- 構造体
- パッケージ
- エラーハンドリング
- ログ出力
- ファイル操作
- リファクタリング

## 実行方法
### ビルド
```bash
go build
```

### 実行
```bash
go run .
```
または対象ファイルを直接実行します。

```bash
go run main.go
```

### モジュール管理
```bash
go mod tidy
```
